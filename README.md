# LeoFlix

Thème CSS pour Jellyfin 12 : sombre, verre dépoli, accent bleu acier.

## Installation

Dans Jellyfin : **Tableau de bord > Slogan > Code CSS personnalisé**, mettre uniquement :

```css
@import url('https://cdn.jsdelivr.net/gh/LeonardSav/Jellyfin_Skin_Leo@v0.35/leoflix.css');
```

Pour mettre à jour, changer seulement le numéro de version (`@v0.35`).

## Plugins utilisés (facultatifs)

- Editor's Choice (bandeau du film en tête sur l'accueil)
- File Transformation (nécessaire à Editor's Choice dans Docker)
